# نظام إدارة الإجازات — نسخة Web جاهزة للنشر

هذه نسخة Next.js + Supabase قابلة للنشر على Vercel.
1) أنشئ مشروع Supabase وشغّل `supabase/schema.sql`.
2) انسخ `.env.example` إلى `.env.local` وضع رابط المشروع وAnon Key.
3) شغّل `npm install` ثم `npm run dev`.
4) للنشر: ارفع المشروع إلى GitHub ثم اربطه بـ Vercel وأضف نفس متغيرات البيئة.

مهم: لا تضع Service Role Key داخل الواجهة.
